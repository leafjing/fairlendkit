# Alternative-data source review records

This directory contains metadata and review evidence only. It must not contain
raw, sampled, transformed, or row-level third-party data.

- `pending/` holds unverified candidate records.
- Approved/rejected registers are created only after independent review under
  the [AD-D0 admission contract](../alternative-data-source-admission.md).

Being listed here is not endorsement, admission, or permission to download.
Every candidate must be rechecked against the original publisher, exact version,
current license and terms, redistribution rights, field dictionary, and temporal
semantics. Mirrors, papers, catalog pages, and prior third-party use are leads,
not authoritative evidence.
