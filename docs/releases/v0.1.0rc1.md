# FairLendKit 0.1.0rc1 release notes

Release type: GitHub prerelease. This release is not published to PyPI.

## Highlights

- Preserves the reviewed Milestone 3 audit engine and Milestone 4 installed CLI
  workflow with canonical JSON, CSV, and HTML reports.
- Adds strict alternative-data source, temporal-leakage, revision, reversal,
  coverage, and reason contracts (AD-0).
- Adds disclosure-controlled aggregate quality evidence with primary and
  complementary suppression and historical-release constraints (AD-1).
- Adds explicit cash-flow, rent, and utility adapters and deterministic typed
  signal profiles using Decimal amount semantics (AD-2).
- Adds disclosure-controlled credit-risk diagnostics with deterministic
  counter bootstrap, reliability gates, and complete trace evidence (AD-3).
- Adds potential proxy-risk screening with fixed development/holdout modeling,
  paired and stratified bootstrap evidence, typed flags, and canonical JSON,
  CSV, and HTML projections (AD-4).

## Scope and safety boundaries

This prerelease contains no real alternative-data dataset, admitted data
artifact, or live retrieval invocation. The separately reviewed retrieval
harness is not part of this release tree. This release does not authorize data
download, admission, promotion, repository storage, or redistribution.

Alternative-data outputs are screening and review evidence only. They do not
provide threshold recommendations, automated feature removal, model decisions,
or causal, discrimination, legal, or compliance conclusions.

## Compatibility and reproducibility

- Supported runtimes: Python 3.11 and Python 3.12.
- Package version: `0.1.0rc1`.
- Intended tag: `v0.1.0rc1`.
- Merge strategy: merge commit, preserving the complete approved lineage.
- Canonical artifacts are regenerated only for the package-version metadata
  change; analytical values and contracts are unchanged.
