# FairLendKit

FairLendKit is an open-source audit framework for evaluating group outcome disparities, model performance disparities, threshold sensitivity, and potential proxy risks in credit underwriting models.

The project is designed for reproducible practitioner review using public or synthetic data. It does not determine legal compliance and does not provide legal advice.

## V1 scope

- Credit-specific fairness and performance metrics
- Threshold sensitivity and fairness-accuracy frontier analysis
- Exploratory proxy-risk screening
- Reproducible HTML, JSON, and CSV audit outputs
- Synthetic reference workflow and a documented public-data case study

See [Product requirements](docs/product-requirements.md), [Architecture](docs/architecture.md), [Methodology and guardrails](docs/methodology-and-guardrails.md), and [Roadmap](docs/roadmap.md).
